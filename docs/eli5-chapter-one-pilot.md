# 第一章 ELI5 十题试点

## 范围与接入

[第一章题型分类](eli5-chapter-one-classification.md)登记 344 题、16 类。分类按题目的现行主解法组织，一题可以另有其他解法。P8 保留，十道新增试点的数据在 `src/data/teachingChapterOne.ts`。普通题库和 `guidedHints` 沿用原数据。

`TeachingLesson` 按题号注册，包含学习目标、前置知识、题型策略、标准解式和可变长的有序步骤。每步有稳定 ID、目的、白话、延后显示的公式和详细原理。理解检查提供逐选项反馈，连续出错会给基础例子。末段可加入独立判分的迁移题；主动跳过原题检查可以继续，跳过迁移题不会显示迁移答案。模板先共享流程，数学和反馈由各题提供。

`mc-learning-v1`、JSON 备份以及默认解析模式键继续沿用。试点使用既有 `TeachingProgress.transfer` 保存迁移首答结果和后来是否完成，一个样板会话使用一个迁移题。这一证据仅表示当前教学会话里的同策略换题表现，独立完成和延迟复习判定仍用原来的作答记录。

## 验证边界

| 检查 | 目前怎样做 | 仍需人工判断 |
| --- | --- | --- |
| 分类覆盖 | Vitest 将报告 ID 与运行时第一章题库逐项对账 | 多解题选择哪个主模板 |
| 公式及答案 | KaTeX 严格解析，并将标准答案和迁移答案与 SymPy 测例对账 | 某条解释是否准确描述等价变形的条件 |
| 提前泄露 | 浏览器断言检查前无已解公式、错误回答和跳过迁移时无迁移解式 | 提示文字是否在语义上等同于报答案 |
| 迁移一致性 | 十组用同方法构造的原题和迁移题用独立表达式复算，并核对策略 ID | 换条件后是否仍在测同一个技能、学习难度是否相当 |
| 错误反馈及新概念 | 检查选项数、独立反馈、补救文本、前置知识与步骤的完整性 | 反馈是否针对误解、解释是否跳步、前置概念是否充分 |
| 手机布局 | 浏览器在 360px 检查标准解式、教学解式和迁移解式 | 准确测量之外的手机可读性与使用负担 |

数学复算命令为 `python scripts/check-eli5-chapter-one.py`，依赖 SymPy。十个原题、十个迁移题分别计算。P8、教学模式、备份和辅助作答的分类继续有原有回归。

## 扩展估算与暂停点

全章 192 题初筛可沿用现有类模板，152 题先做题级复核。P8 和十题试点都属于前一组，因此剩余 181 道模板候选、152 道需独审，共 333 道。按模板题 8–15 分钟、独审题 20–40 分钟，再加批次对账和回归，粗估 **90–180 人时**。其中图题、形式证明、含前置积分的题目偏上限。这个估计需要用下一小批实际耗时更新。

待用户体验确认后，优先在正弦配凑、接缝和等价小量三组各选少量题，双人抽查纸笔解答和迁移首答，再扩展到其余题型。阶段内不批量生成剩余条目，不合并主线，不发布。

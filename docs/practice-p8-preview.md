
# 练习中心 · P8 样板

基线为 `main` 的 `a08419f`，应用版本为 0.31.0。设计与验收分支为 `ui/practice-p8`。打开 [P8 新版样板](http://127.0.0.1:4193/#/practice?problem=p8&ui=study)。同一预览服务器上去掉 `ui=study` 即可对照原界面。

## 现有体验审查

- 默认 P8 题卡有 8 个操作入口，包括检查、提示、模式切换、默认模式、完整解析、判分说明和卡住反馈，题卡上方另有 3 个题目导航按钮。手机端容易把设置和模式切换当作做题的下一步。
- 数值题同时维护标准提示、ELI5 和可展开的完整解析。引导启动后，输入区和部分模式操作仍留在上方，新出现的步骤叠在下方。
- 书写题使用纸笔、自评和参考解析，入口及动作顺序与数值题不同。已有证明题需要维持纸笔与参考答案对照，后续设计可共用四状态外壳。
- 原版折叠了教学历史，但题面、作答、模式和解析仍共用页面纵向空间。较窄屏幕上，继续按钮与反馈容易分离。

## 样板信息架构

| 状态 | 页面重点 | 可操作内容 |
| --- | --- | --- |
| 独立解题 | 原题、公式与输入框 | 检查答案是主要动作。引导教学和完整解法在操作区下方 |
| 引导教学 | 进度、当前目标与一个检查 | 答完才揭示算式。若有迁移题，先答迁移题。答错保留反馈和补救，历史、原题和详细原理按需展开 |
| 完整解法 | 独立排版的数学推导 | 返回作答或重新练习。回到题目时保留输入 |
| 完成与复习 | 本次结果与学习证据 | 继续下一题、重练或查看错题。先看过解法或引导，再答对会记为辅助完成 |

样板沿用同一套教学内容、判分和学习记录协议。横向大屏用单列阅读宽度，手机保持顶端返回入口和清晰的主操作。手机和桌面均复用应用原有的浅色与深色主题。常规练习仍使用原界面。

## 恢复检查点

在本分支运行 `npm ci`、`npm run build` 和 `npm run preview -- --host 127.0.0.1 --port 4193 --strictPort`。端到端回归使用 `PLAYWRIGHT_BASE_URL=http://127.0.0.1:4193` 和 `ELI5_OFFLINE_TEST=1`，覆盖 `practice-focus.spec.ts`、`teaching.spec.ts`、`teaching-chapter-one.spec.ts` 及 `teaching-production.spec.ts`。用户验收后再设计书写题的同一套视图并决定默认入口。正式版本号和发布流程沿用原基线。

本轮验收于 2026-11-22 记录。生产网页构建、类型检查、Lint、CSS 校验、131 项单元与组件测试及 96 项在线浏览器检查通过。P8 新样板在桌面和手机浏览器模拟中均通过生产缓存离线交互。旧版桌面离线烟测出现过间歇性脚本和样式加载失败，另一次独立运行通过；需将该问题与本次界面评审区分。

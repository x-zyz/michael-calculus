# 教材课程大纲

以项目所有者提供的教材目录第 I–X 页为准。页码指纸书起始页，星号表示教材标注的选学内容。应用里的课时可以细分，一个教材小节可对应多个课时。

新课时、练习、公式和实验按下面的章与节归档。课程中心从 `src/data/textbookSections.ts` 读取当前开放的小节。新增内容时同步登记小节与课时 ID，保留已有 ID，以便继续使用阅读进度、错题及公式复习记录。第六至八章目前供后续编写使用，有可学习、可练习的内容时再开放对应入口。

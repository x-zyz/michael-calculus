# P8 分层教学样板

## 接入契约

- 数据在 `src/data/teaching.ts`，按原有题目 ID 注册。未注册的题继续使用原来的练习流程。保留题库的 `hints`、`guidedHints`、答案和解析，教学扩展不依赖任何批量改写。
- 每份 `TeachingLesson` 提供标准解式和有序步骤。步骤使用稳定 ID、一个目标、一个关键算式、白话解释和可选展开的详细原理。理解检查提供选项、正确索引、逐选项反馈和连续出错时的前置小例子。
- `mc-learning-v1` 和 JSON 备份版本不变。提交答案时，原 `hints` 记录辅助暴露量，取原提示数、教学展开步数、完整解答是否已查看三者的最大值。可选 `teaching` 追加已见步数、通过数、跳过数和答错次数。旧数据无需迁移。当前步骤的浏览界面是临时状态，教学证据随作答写入。
- P8 练习卡将正确作答分为辅助、独立和延迟复习。两次独立正确作答相隔至少 24 小时才显示延迟复习成功。普通练习汇总和 Formula Mastery 本轮维持现行逻辑。

## 后续验证

先用 P7 检验同类模板，从底数里要配的那一块复用到找到外部指数，保留针对正系数的反馈。再用 P9 检验异类模板，可先检查用户是否会认出角度内层，再检查是否把内层系数平方。前置知识暂用检查内的小例子表示，等跨三题有重复证据时再考虑显式前置知识 ID。推广前应加入同类新题上的独立作答证据，以检验能否迁移，单题重复表现只能衡量该题上的回忆。

由教学层维护步骤结构和学习证据，数学内容仍由题库侧维护。先以固定题号试点，确认数学推导、KaTeX 和 360px 布局后再扩大注册表。暂停打标签、APK 和 Release，直到用户另行授权。

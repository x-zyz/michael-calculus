# Michael Calculus v1.0.0 候选说明

## 相对 v0.31.0

- 第一章已有完整 ELI5 的 41 道题使用新版练习流程。29 道数值题自动判分，12 道书写推导题使用纸笔与自评。覆盖范围与题号见 [推广报告](eli5-interface-rollout.md)。
- 新版将独立解题、引导教学、完整解法与结果分开。引导时可对照原题，理解检查及迁移题保留延迟揭示、针对性反馈和补救。首次答错优先重练，连续答错时突出引导。查看参考答案后的正确作答记为辅助完成。
- 保留 1,693 道现有题目。第一章其余 303 道及其他未注册题目沿用已有交互、题库和提示。没有新增自动证明判分。
- 修复生产 PWA 冷启动时，源站不可用且预缓存因 Vary: Origin 匹配落空的问题。详见 [离线根因与复验](pwa-offline-review.md)。
- 候选版本将 React Router 更新至 7.18.6，Vite 更新至 7.3.8。生产依赖审计中原有 3 项高危已清除，KaTeX 与 esbuild 仍各有 1 项低危报告。

## 真机验收清单

1. 在真实 Android 设备记录当前正式版 0.31.0 / 42，保留原安装，先导出一份含课程进度、作答、错题和公式记忆的 JSON。
2. 在固定签名候选 APK 就绪后，先核对包名、1.0.0 / 43、固定证书和非调试标志，再覆盖安装。禁止卸载后重装代替升级测试。
3. 比对升级前后的课程、作答、错题、Formula Mastery 和主题。验证备份恢复能重读旧数据。
4. 在线打开应用后断网，彻底关闭再重新打开。完成 P8、一个数值题和一题纸笔推导，确认 KaTeX、原创题面、反馈、迁移题和记录仍可用。
5. 恢复网络后检查应用内更新。稳定渠道应继续报告既有正式版本，不向设备推送候选。
6. 由用户确认 UI 和真机结果后，再另行确认是否正式发布。安装失败、数据差异、离线故障都要记录，不用清除旧数据绕过。


## 质量审核

- 已通过候选 PWA 构建和 TypeScript、ESLint、CSS 检查。P8、十题试点及 Batch 1 的原题、两侧极限和迁移题按现有 SymPy 脚本复算。
- 134 项 Vitest 和 5 项固定签名／旧备份协议测试通过。覆盖原有学习记录、公式记忆、错题和 JSON 恢复。
- 浏览器旧版升级用例在桌面和移动 Chromium 均通过。它在同一来源运行正式 v0.31.0 后切换到候选，等待新 Service Worker 实际接管，核对旧缓存淘汰，再断网打开新版并比对原有作答 JSON。首次写的用例未等待控制器接管，触发了旧壳提前重开，补上接管同步后复测通过。
- Android Capacitor 同步、:app:assembleDebug 与 :app:lintDebug 通过。已用 aapt 验证内部构建为 com.michael.calculus.dev / 1.0.0-dev / 43。它仅验证构建链路。
- 未验证固定签名候选 APK、Android 真机覆盖安装、升级后的原生 JSON 备份与断网重开。当前连接的设备均为模拟器，本地没有候选签名所需环境。未跑全 1,693 道题的逐题旧版布局扫描，已注册 41 道新版题逐题检查。
- 待确认项为真实设备验收、独立候选签名构建与用户明确批准。正式发布标签、GitHub Release 与 ByteVirt 稳定通道都未更新。

最终候选浏览器回归 212 项通过，含全部 41 道四状态练习、第一章既有教学、纸笔自评、360px 公式布局、错题复习、离线冷启动和缓存升级。

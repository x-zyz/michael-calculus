# Michael Calculus v1.0.0 候选说明

v1.0.0 将新版练习扩展到第一、第二章。第一章 344 道全部覆盖，其中 303 道为本轮新增。第二章新增 258 道，范围为教材 §2.1–§2.5 加 29 道总习题二。现有教材目录将总习题二列在第二章末尾，没有单列 §2.6。

每道新增题都有针对原题的讲解、带反馈的理解检查，以及一道同策略数值迁移题与解答。数值题自动判分，推导题、证明题和作图题由学习者自评。查看引导或参考解法后完成的作答仍标记为辅助完成。其余章节沿用已有练习。题库、进度、错题和公式记忆保留原有 ID 与备份格式。

PWA 沿用此前候选的离线冷启动和缓存升级修复。ByteVirt 发布流程在上传后回读公网签名清单与 APK，并逐字节核对发布工件。

## Android 签名与验收

- 正式基线为 0.31.0 / 42，先前签名候选为 1.0.0 / 43。本轮目标为 1.0.0 / 44，包名 `com.michael.calculus`，使用仓库固定证书签名。
- 在独立的备用真机测试环境，分别从 42 和 43 覆盖安装到最终签名包。记录安装前后的版本、课程进度、作答、错题和公式复习。对照 JSON 恢复，并在断网强制停止后重开应用，核对离线新记录能否在再次重开后保留。
- 确认 PWA 和应用内更新能够保留既有学习数据。正式发布后核对 GitHub APK、ByteVirt 公网签名清单及 APK 哈希。

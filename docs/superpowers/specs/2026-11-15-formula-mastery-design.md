# 公式记忆中心（Formula Mastery）· MVP 设计

> 状态：待用户确认 · 目标基线：v0.5.0 之上 · 作者：Antigravity（根据 Michael 的方案整理优化）

## 1. 为什么做

学生缺的往往不是公式表，而是一个能让自己**把公式真正记住、并在做题时想得起来该用哪个**的地方。

Michael 本人的经历就是需求来源：背下了 \(\lim_{x\to0}\frac{\sin x}{x}=1\)，却不一定马上会做 \(\lim_{x\to0}\frac{\sin 3x}{5x}\)。所以这个模块要覆盖两段路：

1. **记住**：从认出公式，到独立默写（L1–L3）。
2. **会用**：知道适用条件，并且看到题目能选对公式（L4–L5）。

第一位用户就是 Michael 自己：每天上高数课，用手机（Capacitor Android APK）复习，发现问题后再迭代。

## 2. 目标 / 非目标 / 反目标

**目标（MVP）**

- 收录第一到第三章的核心公式，按章节和课程归类，并关联已有的 12 节课程。
- 支持三种默写模式：填空、完整默写、随机抽查。默写在纸上或心里完成，翻开答案后自评。
- 每张卡片单独做间隔复习：答对拉长间隔，忘记缩短间隔。
- 掌握度 L0–L5 **由完成的题型自动推算**，不让用户直接给自己打等级。
- 反向识别：给一道题，从 4 个公式中选出该用哪个，由程序自动判对错。
- 与练习中心共用数据：做题时点“卡在公式上了”，相关公式立即进入今日复习；关联题目答对后，计入该公式的 L5 证据。

**非目标（后续版本再做）**

- 数学键盘输入、表达式等价判定、手写 OCR、AI 评分。
- 云同步、账号、自定义公式。
- 更复杂的复习算法（如 FSRS）。

**反目标（即使功能都能跑，出现以下情况也算失败）**

- 变成一张只能往下翻的公式表。
- 自评让等级虚高：点了“记住了”就显示 L3。
- 复习量越堆越多，几天不打开就有上百张到期卡，用户直接放弃。
- 首页出现模拟数字。必须延续项目“只显示真实进度”的原则。

## 3. 约束

- 技术栈：React 19 + TS + Vite + 本地 KaTeX + Capacitor 7，离线可用，不调用任何网络服务。
- 布局：手机 360px 为第一优先，公式不能横向裁切，最小字号 11px，底部导航不能遮挡控件（沿用 v0.5.0 验收标准）。
- 存储：localStorage。使用**独立 key** `mc-formula-v1`，不改 `mc-learning-v1` 的结构，避免影响旧数据兼容（0.2.0–0.4.0）。
- 判题：沿用项目原则“不使用 `eval`，不声称能判断任意符号等价”。

## 4. 方案比较（输入方式）

| 方案 | 做法 | 取舍 |
|---|---|---|
| A. 纸笔默写 + 翻卡自评 **（采用）** | 在纸上或心里写，点“显示答案”对照，再选 记住了 / 模糊 / 忘记了，并勾选错因 | 实现成本最低；手机上不用输入复杂公式；自评有主观性，用“题型决定等级上限”来约束 |
| B. 数学键盘输入 + 手动对照 | 用 KaTeX 键盘输入，再与答案并排对照 | 手机上输入分式和极限很慢；不能自动批改时，输入本身没有额外价值 |
| C. 数学键盘 + 自动等价判定 | 解析表达式后做数值或符号等价检查 | 价值最高，但误判风险和开发量都大，放到后续版本 |

选择 A：第一版的瓶颈在“坚持每天用”，不在输入。错因标签从第一版开始记录，以后做方案 C 时可以直接用这些数据。

## 5. 核心概念与数据模型

### 5.1 公式 → 卡片 → 复习记录

一个公式对应多张不同题型的卡片。这样掌握度可以按题型推算，练习题也只需要标注公式 ID。

```ts
// src/data/formulas.ts
export interface Formula {
  id: string;                 // 如 "sin-limit"
  chapter: 1 | 2 | 3;
  lessonId?: string;          // 关联已有课程，如 "sine"；暂无课程的公式可以不填
  group: string;              // 章节内分组，如 "重要极限" "等价无穷小" "基本求导公式"
  name: string;               // "第一个重要极限"
  latex: string;              // 完整标准式
  cloze: { latex: string; answer: string }[]; // 填空版本，用 \boxed{\ ?\ } 挖空，每个元素是一张填空卡
  conditions: string;         // 适用条件，如 "x→0 且分子分母的 sin 内与分母一致"
  conditionQuiz?: { question: string; options: string[]; correct: number }; // L4 用的条件判断题
  pitfalls: string[];         // 常见错误
}

export type CardKind = "cloze" | "recall" | "condition" | "recognize";
// 卡片 ID：`${formulaId}:${kind}[:index]`，由公式数据派生，不单独存储
```

**反向识别题**优先复用已有题库：给 `Problem` 增加可选字段 `formulaIds?: string[]`，第一个 ID 是首选公式。识别题显示该题的 `formula`，正确答案是 `formulaIds[0]`，3 个干扰项从同章节、同分组的其他公式中抽取。没有标注 `formulaIds` 的题不生成识别题。

### 5.2 本地存储 `mc-formula-v1`

```ts
interface FormulaStore {
  version: 1;
  cards: Record<string, {
    box: number;        // 0 = 未学，1..6 对应复习间隔档位
    due: string;        // 下次复习日期，本地日期 YYYY-MM-DD
    lapses: number;     // 累计忘记次数
    lastResult?: "good" | "fuzzy" | "forgot";
  }>;
  reviews: {            // 最多保留最近 2000 条
    cardId: string;
    at: string;         // ISO 时间
    mode: "learn" | "due" | "spot";   // 新学 / 到期复习 / 随机抽查
    result: "good" | "fuzzy" | "forgot";
    errorTags: FormulaErrorTag[];
  }[];
  stuck: { formulaId: string; problemId: string; at: string }[]; // 来自练习中心的“卡在公式上了”
  settings: { newPerDay: number };  // 默认 5
}
```

读取时与 `mc-learning-v1` 一样逐字段校验：未知的卡片或公式 ID 丢弃，数据损坏就回退为空，写入失败复用现有的 `storageError` 提示。

### 5.3 错因标签（自评时勾选，可多选，可跳过）

`sign` 漏负号或符号写错 · `coef` 系数错 · `power` 指数或幂次错 · `condition` 漏写或写错趋近条件 · `order` 导数阶数错 · `mixup` 和别的公式记混 · `blank` 完全想不起。

## 6. 复习规则

固定档位间隔（单位：天）：`[—, 1, 2, 4, 7, 15, 30]`，对应 box 1–6。

| 自评 | 处理 |
|---|---|
| 记住了 | box +1（最高 6），due = 今天 + 新档位间隔 |
| 模糊 | box 不变（最低 1），due = 明天 |
| 忘记了 | box = 1，lapses +1；本轮末尾再出一次，due = 明天 |
| 反向识别（自动判分） | 答对等同“记住了”，答错等同“忘记了” |

- **每日队列**：先放所有到期卡，再按课程顺序加入新公式，每天最多 `newPerDay` 个（默认 5）。单轮最多 20 张，做完可以再来一轮。
- **积压保护**：到期卡超过 40 张时，首页提示“先清 20 张最久没复习的”，并暂停加入新公式。
- **薄弱**：lapses ≥ 3，或最近 3 次中有 2 次不是“记住了”。
- **随机抽查**：从 L3 及以上的公式中随机抽取。结果按正常规则处理，忘记就降档。
- **卡在公式上了**：相关公式的所有卡片 due 设为今天，并在首页“薄弱”中显示 7 天。

## 7. 掌握度 L0–L5（自动推算）

每一级需要的证据如下。必须**从低到高逐级满足**，显示的是满足的最高一级：

| 等级 | 含义 | 需要的证据 |
|---|---|---|
| L0 | 还没学习 | 没有任何复习记录 |
| L1 | 看见公式能认出来 | 至少学过一次（任意卡片有记录） |
| L2 | 看提示能写出来 | 该公式所有填空卡最近一次都是“记住了” |
| L3 | 能独立完整默写 | 完整默写卡在**两个不同日期**都是“记住了”，且最近一次不是“忘记了” |
| L4 | 知道适用条件 | 条件卡最近一次答对（没有条件卡的公式，L3 直接视为满足 L4） |
| L5 | 能在题目中运用 | 识别题在两个不同日期答对，且最近 14 天内没有该公式的“卡在公式上了”记录；如果有关联练习题，最近一次作答必须正确（读 `mc-learning-v1` 的 attempts） |

要求“两个不同日期”，是为了防止当天反复刷卡造成的短时记忆把等级抬高。降级是自动的：只要最新证据不满足，等级就会回落，不需要额外的降级逻辑。

## 8. 页面与流程（360px 优先）

**入口（我的决定，待你确认）**：不新增第七个底部导航。v0.5.0 的六入口在 360px 下已经很紧，交接文档也要求保留六大模块。改为：

- “错题与复习”页顶部加分段切换：**错题 | 公式**，路由为 `/review/formulas`；
- 学习首页加一张“今日公式”卡片：显示到期数，带“开始”按钮；
- 课程详情页的“定义”标签下加“背这节的公式”链接。

### 8.1 公式首页 `/review/formulas`

- 三个真实计数：**今日到期 / 今日新学 / 薄弱**，加一个主按钮“开始今日复习”。
- 模式切换：今日复习（默认）· 填空 · 完整默写 · 随机抽查 · 反向识别。
- 章节列表：每章显示 L0–L5 分布条，点进去是公式列表（KaTeX 渲染加等级标签），再点进入公式详情。

### 8.2 默写流程

1. 显示卡片：标题（如“第一章 · 两个重要极限”），题干（填空卡显示带 \(\boxed{\ ?\ }\) 的式子；完整默写只显示公式名称和左边部分），进度显示为“3/12”。
2. 提示文字：“先在纸上写完整，再看答案。” 按钮：**显示答案**。
3. 翻开后显示标准式、适用条件和常见错误；底部三个按钮：**忘记了 / 模糊 / 记住了**（大按钮，单手能点到）。
4. 选择“模糊”或“忘记了”时，弹出错因标签条，可以跳过。
5. 一轮结束显示小结：本轮正确率、哪些公式升了等级或降了等级、明天到期数。

### 8.3 反向识别

题干是题目式子（如 \(\lim_{x\to0}\frac{\sin 3x}{5x}\)），下方 4 个 KaTeX 选项。选完立即显示对错，附一句为什么选它，并链接到对应练习题。

### 8.4 公式详情

标准式、适用条件、常见错误、关联课程、关联练习题、当前等级和每一级还缺什么证据（例如“再在另一天完整默写一次即可到 L3”），以及最近 10 次记录。

### 8.5 练习中心改动

- 题目带有 `formulaIds` 时，显示一个次要按钮 **“卡在公式上了”**。点击后列出关联公式，让用户确认是哪一个，然后写入 `stuck`，Toast 提示“已加入今日公式复习”。
- **不**根据答错自动推断“忘了公式”，避免误判。

## 9. 公式清单（MVP 初版，具体写法由实现者按教材核对）

- **第一章**：两个重要极限（`sine`、`euler`，含 \((1+x)^{1/x}\) 和 \((1+\frac1x)^x\) 两种形式）；x→0 时的等价无穷小 9 个（sin、tan、arcsin、arctan、1−cos、eˣ−1、ln(1+x)、(1+x)^α−1、aˣ−1，课程 `infinitesimal`）；连续的定义（`continuity`）。
- **第二章**：导数定义（`derivative`）；基本初等函数求导 13 个（`rules`）；四则运算求导法则：和差、乘积、商（`rules`）；链式法则（`chain`）；微分与线性近似（`differential`）。高阶导数（sin、eˣ 的 n 阶导）和参数方程求导先收录、不关联课程，等课程补上后再关联。
- **第三章**：罗尔定理、拉格朗日中值定理（`mvt`）；洛必达法则及条件（`lhopital`）；单调性判别、极值的一阶和二阶判别（`extrema`）。

合计约 40 个公式。每个至少有 1 张填空卡和 1 张完整默写卡；条件卡优先覆盖重要极限、等价无穷小、洛必达法则和中值定理；p1–p24 中适用的题补上 `formulaIds`。

## 10. 测试与验收

- **单元测试**：复习规则（每种自评的 box 和 due 变化、跨天、积压保护）；掌握度推算（逐级判定、“两个不同日期”、自动降级、L5 读取练习记录）；存储校验（损坏数据、未知 ID、超过 2000 条时截断）。
- **组件测试**：一轮完整流程（显示答案 → 自评 → 错因 → 小结）；练习页点击“卡在公式上了”后，公式出现在今日到期中。
- **E2E**：桌面和 360px 各跑一遍首页 → 复习 → 小结；所有公式卡在 360px 下没有横向溢出。
- 现有的 19 项单元测试和 14 项 E2E 测试必须全部保持通过。

## 12. 我做的决定（请重点检查）

- 第一版不做数学键盘，改为纸笔默写加翻卡自评（理由：主要在 APK 上用，手机输入公式太慢）。
- 不新增第七个导航，入口放在“错题与复习”里（理由：360px 底栏空间不够，并且遵守“保留六大模块”）。
- 等级显示为一条 L0–L5，但每一级都必须有对应题型的证据；L3 和 L5 要求在两个不同日期达成。
- 使用固定间隔档位，不用 SM-2 或 FSRS；每天最多 5 个新公式。
- 练习中心只通过手动按钮报告“卡在公式上了”，不自动推断。

## 数学与题意复核清单

- jc935-1-3-3-8 的双侧结论依赖本节要求两侧都能逼近的约定。采用相对于定义域的极限时，端点可有极限。推广时应把这条约定提前写进题干。
- jc935-1-8-3-2 先按原式 x/tan(2x) 的定义域排除正切的极点，再用等价式求补值。教程若直接把它替换成 x·cot(2x)，会误把原式缺失的点当成已定义。
- jc935-1-1-6-2 的常函数分支仍排除 x=2，且递增或递减只在断点两侧各自成立，不能合并区间。
- jc935-1-review-1-1 的公式只举极限为 3 的情形，题干问的是任意收敛数列。完整通用结论在文字解析中，教学时应把示例和命题区分开。
- 考研选题中涉及变上限积分或高阶展开的条目虽归入第一章，教学前置应单独标明。当前先完成分类和风险标注，未对其余数百道题宣称逐题证明。

## 人工证明复核（2 题）

- `jc935-2-2-13`（第 13 题，零点可导乘连续函数）：
  - 条件：`f` 在 `x=1` 可导且 `f(1)=0`，`g` 在 `x=1` 连续（未必可导），`h(x)=f(x)g(x)`。
  - 复核要点：因 `g` 未必可导，不可套用乘积求导法则；回到导数定义，由 `h(1)=f(1)g(1)=0` 得 `[h(x)-h(1)]/(x-1) = [(f(x)-f(1))/(x-1)]·g(x)`。当 `x→1` 时，前因子趋于有限值 `f'(1)`，后因子由连续性趋于 `g(1)`，由极限乘积法则得 `h'(1)=f'(1)g(1)`。逻辑严密无漏洞。
- `jc935-2-2-14`（第 14 题，函数方程与处处可导性）：
  - 条件：`f: ℝ → ℝ` 对一切实数满足 `f(x+y)=2f(x)f(y)`，且 `f` 在 `x=0` 处可导。
  - 复核要点：
    1. 情况一：`f ≡ 0` 恒为零函数，此时 `f'(x) = 0 = 2f(x)f'(0)` 成立。
    2. 情况二：`f` 不恒为零，取 `x₀` 使 `f(x₀) ≠ 0`，在方程中令 `x=x₀, y=0` 得 `f(x₀)=2f(x₀)f(0)`，消去非零因子得 `f(0)=1/2`。
    3. 对任意 `x ∈ ℝ` 与 `h ≠ 0`，差商 `[f(x+h)-f(x)]/h = [2f(x)f(h)-f(x)]/h = 2f(x)·[f(0+h)-f(0)]/h`。令 `h → 0`，右侧极限存在且等于 `2f(x)f'(0)`，证毕。
    4. 合理性校验：非零解 `f(x) = (1/2)e^(cx)` 满足 `f(x+y) = 2f(x)f(y)` 与 `f'(x) = (c/2)e^(cx) = 2·(1/2)e^(cx)·(c/2) = 2f(x)f'(0)`。

## 2. 人工证明核验（`jc935-6-2-20`）

**命题**：设 $f(x) \ge 0$ 在 $[a, b]$（$a < b$）上连续，常数 $c \le a$。平面图形 $D = \{(x, y) \mid a \le x \le b,\, 0 \le y \le f(x)\}$ 绕竖直线 $x = c$ 旋转一周所得旋转体的体积为
$$V = 2\pi \int_a^b (x - c)f(x)\,dx.$$

**逐步核验**：
1. 在 $[a, b]$ 上作分割，任取典型小区间 $[x, x + dx]$（其中 $x - c \ge 0$）。
2. 该小区间上的窄曲边梯形近似为高 $f(x)$、宽 $dx$ 的矩形，绕 $x = c$ 旋转形成外半径 $x + dx - c$、内半径 $x - c$ 的薄圆柱壳。
3. 体积增量为
   $$\Delta V \approx \pi\left[(x + dx - c)^2 - (x - c)^2\right]f(x) = 2\pi(x - c)f(x)\,dx + \pi f(x)(dx)^2.$$
4. 舍去关于 $dx$ 的高阶无穷小 $\pi f(x)(dx)^2$，得体积微元 $dV = 2\pi(x - c)f(x)\,dx$。
5. 由微元法在 $[a, b]$ 上积分即得 $V = 2\pi\int_a^b (x - c)f(x)\,dx$。特别当 $c = 0$ 且 $a \ge 0$ 时退化为绕 $y$ 轴旋转的经典柱壳公式。逻辑完备无误。

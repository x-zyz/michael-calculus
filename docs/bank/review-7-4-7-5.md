## 人工复核记录（`manual`）

### `jc935-7-4-6`（上册习题 7-4 第 6 题）
- **命题**：证明形如 $yP(xy)\,dx + xQ(xy)\,dy = 0$（其中 $P(u)\ne Q(u)$）的微分方程可经变量代换 $u = xy$ 化为可分离变量方程，并写出其通解表达式。
- **逐步推导复核**：
  1. 令 $u = xy$（在 $x \ne 0$ 的区间内），则 $y = \dfrac{u}{x}$，求微分得 $dy = \dfrac{x\,du - u\,dx}{x^2}$。
  2. 将原方程两边同乘 $x$ 得 $xyP(xy)\,dx + x^2Q(xy)\,dy = 0$。
  3. 代入 $u$ 与 $dy$，得到 $uP(u)\,dx + Q(u)(x\,du - u\,dx) = 0$，整理为 $u[P(u) - Q(u)]\,dx + xQ(u)\,du = 0$（该代数微分恒等式亦已在 `scripts/check-bank-7-4-7-5.py` 中通过 SymPy 符号验证）。
  4. 当 $P(u) \ne Q(u)$ 且 $u \ne 0, x \ne 0$ 时，两边同除以 $xu[P(u) - Q(u)]$ 实现变量分离：
     $$\frac{Q(u)}{u[P(u) - Q(u)]}\,du + \frac{dx}{x} = 0$$
  5. 两端积分得通解 $\displaystyle\int \frac{Q(u)}{u[P(u) - Q(u)]}\,du + \ln|x| = C$（其中 $u = xy$）。
- **结论**：逻辑严密，无跳步，复核通过。

## 已实现

- React 19 + TypeScript + Vite，固定依赖版本和 npm lockfile。
- Tailwind CSS、统一主题变量、浅色/深色模式及本地主题偏好。
- 六大模块路由：学习首页、课程中心、数学实验室、练习中心、错题与复习、AI 教师。
- 桌面主导航和移动端底部导航提供五个可用入口。AI 教师可从首页下方查看开放状态。
- 课程五步阅读、专注答题、独立实验页、公式设置抽屉、数据备份设置页、学习路径说明、键盘操作和焦点恢复。
- Vitest 组件回归测试、Playwright 桌面与移动端（360px）布局及学习闭环端到端测试、ESLint 与类型检查。

目前已开放课程与实验：
- **第一章 · 函数、极限与连续（5 节）**：函数极限、第一个重要极限、第二个重要极限、等价无穷小替换、连续性与左右极限。
- **第二章 · 导数与微分（4 节）**：导数的定义与切线、基本求导法则与初等函数导数、复合函数求导（链式法则）、微分的概念与线性近似。
- **第三章 · 中值定理与导数的应用（3 节）**：罗尔定理与拉格朗日中值定理、洛必达法则与未定式极限、函数的单调性与极值判别。
- **第四章 · 不定积分与定积分（3 节）**：原函数与不定积分、定积分与黎曼和、微积分基本定理。
- **五种学习视图**：直觉、实验、定义、例题、练习，每节课程的「实验」环节自动关联对应数学模型。
- **四类交互实验**：
  1. **左右极限逼近实验**：可去间断 `(x² − 1)/(x − 1)`、第一个重要极限 `sin x / x`、第二个重要极限 `(1 + x)^(1/x)`、等价无穷小 `(1 − cos x)/x²`、跳跃间断分段函数；带极限参考线、坐标标注与误差读数。
  2. **割线与切线逼近实验**：支持 `f(x) = x²`、`f(x) = x³ − x`、`f(x) = √x`、`f(x) = (2x − 1)²` 在定点处的左右步长逼近，实时显示割线、切线、增量 `Δx/Δy`、差商斜率以及切线微分线性近似 `dy = f'(x₀)h` 与真实增量 `Δy` 的高阶误差比。
  3. **中值定理与导数应用实验**：支持拉格朗日中值定理平行弦切点 `ξ` 几何观察、洛必达法则 `(eˣ − 1 − x)/x²` 与导数比 `(eˣ − 1)/(2x)` 同步逼近（`x = 0` 处严格未定义）、以及三次函数 `f(x) = x³ − 3x` 的一阶导数单调判别与二阶导数驻点凹凸性判别。
  4. **积分实验**：移动积分常数，比较左端点、中点和右端点黎曼和，观察变上限积分的差商。
- **30 道受限数值题与章节/错因诊断**：支持整数、小数与分数输入（如 `3/5`、`-6`、`1/2`、`1/6`），提供三级提示、答案解析、按章节与错因标签（`errorTag`）筛选练习、各章薄弱考点（`weakTags`）统计及错题重练；首页显示阅读进度和上次所学课程，复习页显示累计作答。

公式使用本地 KaTeX，APK 内置页面和字体。使用带版本号的 `localStorage`（`mc-learning-v1`、`mc-theme`）保存阅读完成状态、最近知识点、最近 500 次作答和主题偏好，兼容 0.2.0 / 0.3.0 / 0.4.0 升级数据；保存失败会显示提醒。作答仅检查预设数值答案（绝对误差 ≤ 10⁻⁶），不使用 `eval`，不宣称判断任意符号等价或推导过程。

## 本地运行

需要 Node.js 22.12+ 与 npm。

```sh
npm ci
npm run dev
npm run typecheck
npm test
npm run lint
npm run check:css
npm run build
```

浏览器自动化测试（本地）：

```sh
npx playwright install chromium
npm run test:e2e
```

也可设置 `PLAYWRIGHT_BASE_URL` 对已有预览运行测试。

## 发布

`npm run build` 生成 `dist/`。Hash 路由支持静态托管的刷新与深链接，无需服务器重写。

## 安卓 APK

安卓工程位于 `android/`，使用 Capacitor 7 封装本地 `dist/`，无需网站登录或联网加载首页。应用名为 **Michael calculus**，包名 `com.michael.calculus`，版本 `0.9.0`（versionCode 14）。支持 Android 8.0（API 26）及以上，Android System WebView / Chrome 需为 111 或以上。

已处理应用图标、启动画面、安卓返回键，以及 Android 15 系统栏边距。主题偏好与学习记录在应用自己的 WebView 本地存储中保存，与浏览器数据相互独立。

### 在 Android Studio 或命令行构建

安装 JDK 21、Android SDK Platform 35、Build Tools 35.0.0，执行：

```sh
npm ci
npm run android:sync
npm run android:debug
```

或使用 `npm run android:release` 构建 release APK 并使用签名密钥签名。每次改动前端后重新执行 `npm run android:sync`，确保 APK 包含最新资源。

### 自有更新服务发布

发布标签触发 GitHub Actions。Android 构建任务先验证并发布固定签名 APK，随后 ByteVirt 任务下载并复核该 APK，使用专用 Actions Secrets 签署更新清单，通过固定主机公钥的 SSH 连接发到高数稳定通道。已有版本可在 Actions 中手动运行「Publish Android update to ByteVirt」，填写现有标签即可补发，无需重新构建。

清单序号等于 Android versionCode。补发相同 APK 会重用服务上已经签名的原清单，避免覆盖同序号内容。清单有效期为 90 天。
